# NoCodeML-NoM

<h3>🚀 No-Code ML: NoM</h3>

NoM — это мощная и интуитивно понятная платформа, созданная для тех, кто хочет использовать силу машинного обучения, не написав ни единой строки кода. Загружайте данные, готовьте их к анализу и обучайте модели в несколько кликов.

<h3>🌟 Ключевые особенности</h3>

Проект реализует полный цикл работы с данными (End-to-End Pipeline) через удобный графический интерфейс:

<ol>
  <li><b>Data Upload</b>: Быстрая загрузка табличных данных в формате .csv.</li>
  
  <li><b>Data Analysis</b>: Графическое представление, создание сводных таблиц и группировка данных для понимания структуры.</li>
  
  <li><b>Data Edit</b>: Удаление лишних признаков, генерация новых колонок, работа с пропусками, применение фильтров и многое другое.</li>
  
  <li><b>Train Model</b>: Возможность обучить модель на загруженном датасете с выбором различных параметров:
      <ul>
        <li>Target column</li>
        <li>Split ratio</li>
        <li>Text encoder</li>
        <li>Scaler</li>
        <li>Model type</li>
      </ul></li>
  
  <li><b>Auto-ML Mode</b>: Режим «Автопилот» сам подберет оптимальную стратегию обработки текста, скейлинг и архитектуру модели.</li>
  
  <li><b>Model Management</b>: Сохранение обученных моделей в личном кабинете и экспорт в формате .joblib для интеграции в реальные приложения.</li>
</ol>
